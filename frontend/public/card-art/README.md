# Card artwork

The SVGs in this folder are bundled with the frontend so card artwork never
depends on a third-party image service. Artwork is per issuer, not per card:
every bank has one tile, and `generic.svg` covers an issuer we have no mark
for. Each tile is a single flat background colour with the bank's logo in the
top-left corner, and nothing else.

The bank marks are reproduced from the banks' public brand materials and are
used here only to identify the issuers in the card catalogue. Refresh against
the current official brand guidance before changing a mark:
